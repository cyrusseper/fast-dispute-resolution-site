# Fast Dispute Resolution Site

Standalone marketing website for Fast Dispute Resolution.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deploy this folder as its own Vercel project and connect:

```text
fastdisputeresolution.com
```

The primary CTA redirects to:

```text
https://artemischat.com/rooms/fast-dispute-resolution
```

## Languages

The landing page supports:

```text
en, es, pt, fr, ar, fa, ru, zh, hi
```
